Phoenix Playground

Poke at NTRU lattice-based encryption using the real library running on this machine.

Learning tool only. Phoenix is unaudited and not constant time, and this page sends keys to a local server in the clear. Use throwaway keys here.

2. Seal

3. Unseal

Decrypt with the private key. Flip a bit first to watch authentication fail.

Textbook NTRU with N = 7, p = 3, q = 41

Every intermediate polynomial, small enough to check by hand. Leave a field blank for a random choice, or type up to 7 coefficients from the constant term upwards (-1 0 1 1 -1 0 1 means x⁶ − x⁴ + x³ + x² − 1).

Round-trip test and timings

Each round generates a fresh key pair, encapsulates, decapsulates and checks the secrets match, then flips one ciphertext bit and checks the secret no longer matches.

Built-in parameter sets

“Worst case” is the largest coefficient p·r·g + f·m can ever have. It must not exceed the limit ⌊(q−1)/2⌋, which is what makes decryption failures impossible.
